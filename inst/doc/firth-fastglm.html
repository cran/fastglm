Firth Bias-Reduced GLMs with ‘fastglm’

Jared Huling

2026-11-07

Maximum likelihood estimates can have substantial bias in small samples. In logistic regression, a predictor or combination of predictors may perfectly distinguish successes from failures, a condition called separation. The ordinary coefficient estimates can then grow without reaching finite values. Mean bias reduction adjusts the estimating equations to reduce their leading small-sample bias; for logistic regression with a logit link it also provides finite estimates under separation when the design has full column rank. The fastglm implementation uses the mean-adjusted score method of Firth (1993) and Kosmidis and Firth (2009), selected by firth=TRUE:

fastglm(x, y, family = binomial(), firth = TRUE)

A score is the derivative of the log likelihood with respect to a parameter. Ordinary maximum likelihood sets these derivatives to zero. Mean bias reduction instead sets adjusted scores to zero. For logistic regression with a logit link, this adjustment can be obtained by adding half the log determinant of the information matrix to the log likelihood. The general adjustment need not correspond to such a penalty for other families or links.

The coefficients are computed by iteratively reweighted least squares (IRLS), a sequence of weighted regression updates. Bias reduction changes the temporary response used in each weighted regression by

\[ \xi_i = \frac{\phi \, h_i \, \mu''(\eta_i) \, V(\mu_i)}{2 \, w_i \, [\mu'(\eta_i)]^3} \]

Here \(X\) is the predictor matrix, \(\eta_i\) is the linear predictor, and \(\mu(\eta_i)\) is the fitted response mean. The derivatives \(\mu'\) and \(\mu''\) describe how that mean changes with the linear predictor. The variance function is \(V(\mu)\), \(w_i\) is the supplied prior weight, and \(\phi\) is the dispersion controlling response variation. The diagonal working-weight matrix has entries \(W_{ii}=w_i[\mu'(\eta_i)]^2/V(\mu_i)\).

The value \(h_i\) is the \(i\)th diagonal of \(H = W^{1/2} X (X^\top W X)^{-1} X^\top W^{1/2}\). These diagonal values, called leverages, describe the relative influence of each predictor row in the weighted-regression step. They determine how strongly that row’s temporary response is adjusted. For families with unknown dispersion, its estimating equation must also be adjusted. The resulting joint calculation corresponds to the AS_mean option in brglm2.

The additional computation depends on the family, predictor dimension, and number of iterations. Leverage calculations use the matrix decomposition from the weighted regression. Gamma models also require solving an adjusted dispersion equation, so avoiding repeated distribution calculations is particularly useful for that family. Timings later in this vignette compare the complete fits and check agreement before reporting speed.

library(fastglm)

Logistic regression under separation

The sex2 dataset from logistf illustrates logistic regression with separation (Heinze and Schemper, 2002). We compare finite bias-reduced estimates from fastglm with those from logistf. The maximum likelihood estimate, abbreviated MLE, refers to the ordinary fit without the bias adjustment.

data(sex2, package = "logistf")
X <- model.matrix(~ age + oc + vic + vicl + vis + dia, data = sex2)
y <- sex2$case

fit_f <- fastglm(X, y, family = binomial(), firth = TRUE)
fit_l <- logistf::logistf(case ~ age + oc + vic + vicl + vis + dia,
                          data = sex2, pl = FALSE, plconf = NULL,
                          control = logistf::logistf.control(
                              lconv = 1e-12, gconv = 1e-12, xconv = 1e-12,
                              maxit = 200L))

General GLM families

The supported response distributions are binomial, Poisson, Gaussian, Gamma, inverse Gaussian, and negative binomial with theta supplied as a fixed value. The standard family definitions must be used because the bias adjustment depends on distribution derivatives beyond those needed for an ordinary GLM. Quasi families, Tweedie families, and user-modified family calculations are therefore excluded from this estimator.

The following examples compare coefficient estimates with the AS_mean option in brglm2::brglmFit(). Numerical agreement depends on the stopping tolerances and on how well the predictors distinguish the separate coefficient effects. The log, inverse, and other links specify how the response mean is related to the linear predictor.

library(brglm2)
set.seed(123)
n <- 500
x1 <- rnorm(n);  x2 <- rnorm(n)
X <- cbind(1, x1, x2)
eta_true <- 0.5 + 0.3 * x1 - 0.2 * x2

Binomial (logit, probit, cloglog)

y_bin <- rbinom(n, 1, plogis(eta_true))

Standard errors

Standard errors describe uncertainty around the fitted coefficients. The reported covariance uses the expected information, which measures how much information the fitted response distribution supplies about those coefficients, evaluated at the bias-reduced estimate. Its diagonal entries give squared standard errors. This is a model-based local approximation; it does not use the curvature of a penalized log likelihood.

Binomial, Poisson, and fixed-theta negative-binomial models have dispersion one. For Gaussian and inverse Gaussian models, the mean-adjusted dispersion estimate is \(D/(n-p)\), where \(D\) is the deviance, \(n\) counts observations with positive weight, and \(p\) is the design rank. The deviance measures discrepancy between fitted and observed outcomes. Gamma dispersion requires an additional adjustment to its estimating equation. The fitted dispersion is used consistently in the coefficient adjustment and the covariance calculation.

f <- fastglm(X, y_bin, family = binomial(), firth = TRUE, tol = 1e-10)
b <- glm(y ~ x1 + x2, data = df, family = binomial(), method = "brglmFit",
         type = "AS_mean", control = list(epsilon = 1e-10, maxit = 200))

cbind(fastglm_SE = f$se, brglm2_SE = summary(b)$coefficients[, "Std. Error"])
#>    fastglm_SE  brglm2_SE
#>    0.09423309 0.09423309
#> x1 0.09910290 0.09910290
#> x2 0.09527990 0.09527990
max(abs(f$se - summary(b)$coefficients[, "Std. Error"]))
#> [1] 4.145295e-14

Assessing convergence

A convergence flag records whether the numerical stopping rule was satisfied. For a bias-reduced fit, the adjusted scores provide a more direct assessment of the equations being solved. An ordinary likelihood score can remain appreciably different from zero at a correctly computed bias-reduced estimate, because the adjustment changes the estimating equation. fastglm_diagnostics() therefore reports the ordinary and adjusted scores separately.

fit_gamma <- fastglm(X, y_gam, family=Gamma("log"), firth=TRUE,
                    tol=1e-10)
fastglm_diagnostics(fit_gamma)
#> Numerical diagnostics
#> Convergence: converged (7 iterations)
#> Solver: column-pivoted QR
#> Estimable coefficients (rank): 3
#> Boundary flag: no
#> 
#>                          Check     Value
#>    Standardized ordinary score   0.01401
#>    Standardized adjusted score 1.941e-11
#>  Standardized dispersion score 3.965e-14
#>    Covariance condition number     1.157
#> 
#> Note: Use the adjusted scores to assess bias-reduced convergence; the ordinary
#>   score need not be zero.

The standardized coefficient diagnostic divides each adjusted score by the square root of its expected information and reports the largest absolute value. This accounts for the units of the predictors when assessing how far the equations remain from zero. The dispersion diagnostic applies the same scaling to the dispersion equation. Both quantities should be close to zero at a numerical solution; they are numerical diagnostics rather than hypothesis-test statistics. Families with fixed dispersion, including binomial and Poisson models, have no dispersion equation to check.

Highly skewed Gamma responses can produce an initial coefficient step that overshoots the solution. For the Gamma log link, the fitting procedure holds the current dispersion fixed and reduces such a step until the coefficient objective decreases sufficiently. The final adjusted scores are then checked, so a small step caused by repeated halving does not by itself establish convergence. convergence.reason distinguishes a successful fit from an exhausted iteration limit or an unsuccessful step search. An unsuccessful fit requires examination before its coefficients or uncertainty summaries are used.

Binomial probit and complementary log-log regressions can also produce excessively large coefficient updates. These links transform a linear predictor into a probability, and a large update can move probabilities so close to zero or one that subsequent calculations become unstable. For these two links, an update is reduced when it would change any fitted linear predictor with positive weight by more than one unit. This changes the numerical path while preserving the adjusted equations. A reduced update alone cannot establish convergence.

The housing data provide an example with grouped binary outcomes. Each row represents a number of respondents in one satisfaction category. The first response column counts respondents reporting low satisfaction, and the second counts all other respondents in that row. Combining rows with the same predictors gives the same grouped-binomial model.

housing <- MASS::housing
housing_design <- model.matrix(~Infl+Type+Cont,housing)
housing_response <- with(housing,cbind(Freq*(Sat=="Low"),Freq*(Sat!="Low")))
fit_housing <- fastglm(housing_design,housing_response,
    family=binomial("cloglog"),firth=TRUE,tol=1e-10)

The display reports how many scoring steps were reduced and the adjusted score at the returned estimates. Sparse, memory-mapped, and streamed fits use the current information matrix for the bias adjustment with these links; using information from an earlier iteration can cause oscillation in difficult cases. Streamed fits consequently require additional reads of the source. These numerical safeguards improve stability but do not guarantee convergence for every dataset or starting value.

Accurate probability calculations are also necessary when outcomes are almost determined by the predictors. A probability can be so close to one that ordinary floating-point subtraction loses the complementary probability, even though that small quantity still affects the bias adjustment. Replacing small probabilities and derivatives separately by numerical lower bounds can therefore change the equations being solved. Probit and complementary log-log bias reduction evaluates these quantities using logarithms of probabilities and stable tail formulas. The likelihood, residuals, covariance, and score diagnostics follow the same calculations. Displayed probabilities can still round to zero or one.

These probability calculations also enter post-fit likelihood and residual summaries and prediction standard errors. The required summaries are computed together, and prediction derivatives are evaluated separately when only those derivatives are needed. This avoids repeated probability calculations and temporary vectors while preserving the adjusted equations and reported quantities. The computational benefit depends on the design and the requested calculations.

The following example separates the binary outcomes at zero exposure. The nuisance predictor, frequency weights, and offsets remain part of the model. The adjusted-score diagnostic assesses the numerical solution directly; agreement between two coefficient vectors would not establish accuracy if both calculations used the same probability approximation.

Solving the adjusted equations is a numerical requirement. It does not make Wald intervals or hypothesis tests exact in small samples, and this example does not assess their coverage or rejection rates.

The adjusted diagnostics are retained with supported fits, including prepared Gamma-log fits that omit their data or covariance. Ordinary scores require the original observations and predictors, and older fitted objects may not contain the stored adjusted diagnostics. An unavailable diagnostic is reported as missing rather than as a zero score.

For streaming fits using method="qr", convergence also depends on the change in fitted linear predictors implied by the remaining adjusted equations. This check is useful when nearly redundant predictors have large, opposite coefficients: their individual updates may remain appreciable while their combined effect changes very little. A joint score diagnostic accounts for combinations of coefficients that separate marginal score checks can miss. The following reader supplies the same Gamma observations in blocks.

gamma_blocks <- split(seq_len(nrow(X)),ceiling(seq_len(nrow(X))/250L))
gamma_reader <- local({
    design <- X
    response <- y_gam
    blocks <- gamma_blocks
    function(k) {
        i <- blocks[[k]]
        list(X=design[i,,drop=FALSE],y=response[i])
    }
})
qr_gamma <- fastglm_streaming(gamma_reader,length(gamma_blocks),Gamma("log"),
                              method="qr",firth=TRUE,tol=1e-8)
fastglm_diagnostics(qr_gamma)

remaining.predictor.step is the largest proposed change in a fitted linear predictor among observations with positive weight. The joint score is scaled by expected information and the number of positive-weight rows; the dispersion diagnostics measure the remaining relative dispersion update and its scaled score. All checks use the reported coefficients and current information. Verification requires additional block reads, and difficult designs can require a further factorization to assess the equations accurately. These costs can matter when reading the source is slow. A failed step search or insufficient numerical precision still produces an unsuccessful fit.

Adjusted scores and penalized likelihood

Mean bias reduction modifies the score equations. For logistic regression, this corresponds to adding half the log determinant of the expected information to the log likelihood. This equivalence does not extend to every family and link. penalized.deviance is therefore reported only for the supported canonical cases; ordinary deviance remains available for all supported families.

f <- fastglm(X, y_bin, family=binomial(), firth=TRUE)
c(deviance=f$deviance, penalized.deviance=f$penalized.deviance)
#>           deviance penalized.deviance 
#>           644.0851           630.0293

The implemented adjustment targets mean bias, which concerns the average estimation error over repeated samples. An adjustment targeting median bias and user-selected strengths of the Jeffreys penalty are outside the current interface.

Profile intervals and tests for logistic regression

An interval based on a coefficient estimate plus or minus a multiple of its standard error is called a Wald interval. This calculation uses a local quadratic approximation to the likelihood, yielding an interval that is symmetric around the estimate. A profile interval instead varies the coefficient of interest and re-estimates the remaining coefficients at each value. The resulting interval can be asymmetric because it follows the shape of the fitted likelihood over a wider range.

For Firth logistic regression with a logit link, confint(..., method="profile") uses the penalized log likelihood described above. Each constrained fit retains all columns of the original information matrix in the penalty. Dropping the tested predictor would change the penalty and therefore the comparison. A candidate coefficient value is included in the interval when twice the decrease in the maximized penalized log likelihood is below the appropriate chi-square cutoff with one degree of freedom.

fit_profile <- fastglm(case ~ age + oc + vic + vicl + vis + dia,
                       data=sex2, family=binomial(), firth=TRUE,
                       tol=1e-10, maxit=200)
profile_ci <- confint(fit_profile, parm=c("age","dia"), method="profile")
cbind(estimate=coef(fit_profile)[rownames(profile_ci)], profile_ci)
#>      estimate      2.5 %     97.5 %
#> age -1.105981 -1.9737884 -0.3074251
#> dia  3.096012  0.7745682  8.0302935
attr(profile_ci,"diagnostics")[,c("parameter","side","converged","lr.error")]
#>   parameter  side converged      lr.error
#> 1       age lower      TRUE -2.331574e-07
#> 2       age upper      TRUE -2.764065e-09
#> 3       dia lower      TRUE  3.265113e-10
#> 4       dia upper      TRUE -6.932233e-12

The parm argument selects the coefficients to profile, limiting the additional fitting work. The diagnostic column lr.error records the difference between the likelihood-ratio statistic at an endpoint and the target cutoff. A failed endpoint is reported as missing with a warning and a diagnostic message. These diagnostics help distinguish an interval obtained successfully from a numerical calculation that requires further examination.

fastglm_profile_test() applies the same comparison to a specified hypothesis. With several coefficients in parm, it tests their hypothesized values jointly while re-estimating the remaining coefficients. The following example tests whether the coefficients for oc and vic are both zero, conditional on the other predictors:

fastglm_profile_test(fit_profile, parm=c("oc","vic"), null=0)
#> Firth penalized likelihood ratio test (asymptotic chi-square reference)
#> Null fit: Firth penalized likelihood
#> 
#>  Statistic df p-value
#>      28.46  2 < 1e-04
#> 
#> Tested coefficients:
#>     Estimate     Null
#> oc  -0.06882  0.00000
#> vic  2.26887  0.00000

The reference chi-square distribution has one degree of freedom for each constrained coefficient. A small p-value indicates that the constrained model fits less well relative to the unconstrained model under this reference distribution. Both the tests and profile intervals use large-sample approximations under independent binomial sampling; profiling does not make their finite-sample calibration exact. Grouped binomial counts and frequency weights are supported when the effective successes and failures are integer counts. Fractional survey or power-likelihood weights require a different inferential justification and are excluded from these procedures.

Profile inference currently requires a retained dense design and response from a converged, full-rank binomial-logit Firth fit. Sparse, mapped, and streaming designs remain useful for fitting, but the profile functions do not convert them to dense form. The default confint() calculation remains the Wald interval, and failed profile calculations return their diagnostics without replacing the result by another interval.

Speed comparison across families

The following comparison uses 10,000 observations and five predictors plus an intercept. Both functions receive the same preconstructed model matrix, so formula processing is excluded from both timings. Each fit is checked for convergence and coefficient agreement before timing. The methods retain their own starting-value procedures, and iteration counts are reported because these procedures and stopping rules affect the work required. These repeated timings describe this dataset and machine; they do not establish a uniform speed advantage across families or designs.

set.seed(123)
n <- 10000;  p <- 5
x1 <- rnorm(n);  x2 <- rnorm(n); x3 <- rnorm(n)
x4 <- rnorm(n);  x5 <- rnorm(n)
X <- cbind("(Intercept)"=1, x1, x2, x3, x4, x5)
eta <- 0.5 + 0.3 * x1 - 0.2 * x2 + 0.1 * x3

families <- list(
    `binomial logit`   = list(fam = binomial("logit"),
                              y = rbinom(n, 1, plogis(eta))),
    `binomial probit`  = list(fam = binomial("probit"),
                              y = rbinom(n, 1, plogis(eta))),
    `binomial cloglog` = list(fam = binomial("cloglog"),
                              y = rbinom(n, 1, plogis(eta))),
    `poisson log`      = list(fam = poisson("log"),
                              y = rpois(n, exp(eta))),
    `Gamma log`        = list(fam = Gamma("log"),
                              y = rgamma(n, shape = 5, rate = 5 / exp(eta))),
    `gaussian identity`= list(fam = gaussian("identity"),
                              y = eta + rnorm(n, 0, 0.5))
)

results <- list()
for (nm in names(families)) {
    fi <- families[[nm]]
    fit_fast <- function() fastglm(X,fi$y,family=fi$fam,firth=TRUE,
                                   tol=1e-8,maxit=100)
    fit_reference <- function() brglm2::brglmFit(X,fi$y,family=fi$fam,
        control=brglm2::brglmControl(type="AS_mean",epsilon=1e-8,maxit=100))
    f <- fit_fast(); b <- fit_reference()
    error <- max(abs(unname(coef(f))-unname(coef(b))))
    stopifnot(f$converged,b$converged,error<1e-5)
    mb <- microbenchmark::microbenchmark(
        fastglm=fit_fast(),brglm2=fit_reference(),times=5L)
    timing <- summary(mb,unit="ms")
    ms <- setNames(timing$median,as.character(timing$expr))
    results[[nm]] <- data.frame(family=nm,fastglm_ms=ms[["fastglm"]],
        brglm2_ms=ms[["brglm2"]],ratio=ms[["brglm2"]]/ms[["fastglm"]],
        fastglm_iterations=f$iter,brglm2_iterations=b$iter,
        max_coefficient_difference=error)
}

The time ratio divides the brglm2 time by the fastglm time, so values above one favor fastglm. Gamma bias reduction requires an additional calculation for dispersion at each fitting iteration. When observations have equal prior weights, their contributions to part of this calculation are identical. Combining those contributions avoids repeating the same special-function evaluations for every observation. A numerical root search then solves the same dispersion equation with fewer evaluations. Gamma models with distinct prior weights also benefit from the improved search, but cannot reuse identical contributions to the same extent.
